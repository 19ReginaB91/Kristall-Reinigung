# Kristall Reinigung Website

Responsive multi-page business website for a cleaning service company in Germany.

Live website: https://kristallreinigung-wesel.de/

## Overview

Kristall Reinigung is a real business website created for a local cleaning service.
The project focuses on clear service presentation, trust-building structure,
mobile-friendly layouts and an easy contact path for customers.

The website was designed and developed from concept to implementation, including
visual direction, page structure, responsive frontend development and final
publishing.

## My Role

- Web design and visual direction
- Frontend development
- Responsive layout implementation
- Content structure and service presentation
- Contact flow and user journey
- SEO-oriented page structure
- Deployment preparation

## Key Features

- Responsive multi-page website
- Homepage, services, about, contact, legal pages and thank-you page
- Clear service sections for private and business customers
- Mobile-friendly navigation and layout
- Contact form flow
- Interactive discount feature with saved discount state
- SEO meta descriptions, sitemap and robots.txt
- Legal pages for Impressum and Datenschutz

## Technologies

- HTML5
- CSS3 / SASS structure
- JavaScript ES6+
- Responsive Web Design
- Git / GitHub
- Netlify

## What This Project Shows

This project shows my ability to create a complete website for a real service
business, combining visual design, frontend implementation and business-oriented
thinking.

The goal was not only to make the website look clean, but to help visitors
quickly understand the service, build trust and contact the company easily.
